## 3. RACE TAXONOMY

### 3.1 THE SYLVANI (Temperate Elves)

| Trait | Detail |
|-------|--------|
| **Lifespan** | 1,200–1,500 years (10:1 ratio to humans) |
| **Maturation** | 150 elven years ≈ 15 human years. Full maturity ~30 elven years. |
| **Height** | Female: 175–180 cm. Male: 165–170 cm. |
| **Build** | Tall, lean, vascular-muscular. Elongated torsos. Moderate hip flare (8–12% wider in females). |
| **Skin** | Pale to pinkish. |
| **Hair** | Silver/Blonde (common). Crimson Red (rare). Grey/White (extremely rare = high mana affinity). |
| **Eyes** | Blue or Green (common). Silver/Golden from birth (extreme mana affinity). |
| **Ears** | Leaf-like. Cartilaginous pinnae with venation patterns. Slight translucency at margins. Swivel 40–60°. |
| **Hair Structure** | Root-like. Mammalian follicles with fibrous, branching medulla. Sensory function. Traps moisture. |
| **Reproduction** | Ovoviviparous. Chorion-wrapped embryos. Gestation: 4–5 months. Birth: 5–10 min active labor. |
| **Gender Ratio** | 10:1 Female-to-Male. |
| **Governance** | Matriarchal pseudo-monarchy → Representative Conclave (post-Aetheric Implosion). Elder Council of 12 advisors. |
| **Culture** | Isolationist (pre-timeskip). Temperate highlands/canopy cities. Value patience, lineage, leyline meditation. |
| **Naming** | Old Norse / Germanic roots + Latin scholarly influence. *Examples: Ylva, Haldor, Sigrune, Veldt, Kaelen.* |
| **Photosynthesis** | Low-to-moderate. Supplemental. Best in filtered canopy light, dawn/dusk leyline resonance. |
| **Hygro-Rhizomes** | Palms/soles. Fast absorption from moss, bark, leaf litter, dew. |
| **Courtship** | Female-initiated. Resonance-based. Tether-offerings. Leyline-tide dances. |

### 3.2 THE SOLANI (Desert/Tropical Elves)

| Trait | Detail |
|-------|--------|
| **Lifespan** | 1,200–1,500 years (same as Sylvani) |
| **Maturation** | Same 10:1 ratio. |
| **Height** | Female: 165–170 cm. Male: 160–165 cm. |
| **Build** | Stockier/more muscular than Sylvani. Broader clavicles. Denser joint cartilage. |
| **Skin** | Bronze/tanned. |
| **Hair** | Brown/Black (common). Blonde (rare). Grey/White (extremely rare = high affinity). |
| **Eyes** | Brown/Black (common). Gold from birth (extreme mana purity). |
| **Ears/Hair** | Same leaf-like/root-like structure as Sylvani. Adapted for salt-air. |
| **Reproduction** | Ovoviviparous. Gestation: 3–3.5 months. Saltwater accelerates chorion hardening. |
| **Gender Ratio** | 2:8 Female-to-Male (opposite of Sylvani). |
| **Governance** | Proto-democratic Clan Councils. Elder-elected. No monarchy. |
| **Culture** | Outgoing. Seafaring. Mercantile. Adopted human inventions centuries ago. Twin births common (~35%). |
| **Naming** | Latin-heavy with phonetic shifts. *Examples: Valeria, Corvae, Marcius, Lucis, Thalassa, Draven.* |
| **Photosynthesis** | Moderate. Adapted to direct sun. |
| **Hygro-Rhizomes** | Palms/soles. Salt-resistant. Filter Na⁺/Cl⁻ while pulling H₂O. |
| **Salt Adaptation** | Osmoregulatory pores (ears, collarbones, ankles). Root-sieve network. Resin cuticle layer. Electrolyte-aerated blood. |
| **Salt Trade** | Primary economic role. Brine-Masters control caravan routes. Three tiers: Rough, Refined, Pure Aether-Salt. |
| **Courtship** | Female-initiated but more balanced. Tide-harmonic exchanges. Salt-drink rituals. |

### 3.3 THE GHARUK (Orcs)

| Trait | Detail |
|-------|--------|
| **Lifespan** | 60–75 years (~½ human). Rare elders (Dune-Weavers) reach 80+. |
| **Maturation** | Rapid. Full adult by 8–12 years. Reproductive readiness ~7 years. |
| **Height** | Female: 160–170 cm. Male: 155–165 cm. |
| **Build** | Compact, blocky. Dense muscle. Heat-vented torso. Calcified plating at pressure points. |
| **Skin** | Olive-green to moss-bronze. Matte finish. Dermal ridges for heat venting. |
| **Hair** | Coarse, dark. Root-fiber structure. |
| **Reproduction** | Ovoviviparous. Gestation: 2–2.5 months. Thick mineral-calcified shells. |
| **Gender Ratio** | Roughly equal. Males slightly stronger. Females have biological upper hand. |
| **Governance** | Clan/Forge-Hold structure. Matriarchs oversee brood-guard. Patriarchs command scout lines. |
| **Culture** | "Burn bright, pass the flame." Oral epics. Forge-markings. Rapid mentorship. |
| **Naming** | Panslavonic/Interslavic + Proto-IE roots + Solani nautical loanwords. |
| **Photosynthesis** | High efficiency. Primary secondary metabolic pathway. Direct solar conversion. |
| **Hygro-Rhizomes** | Palms/soles. Deep-penetrating. Extract from clay, packed silt, moisture-retaining sand. |
| **Water Scarcity** | The Flaw. Need 3–4L/day (up to 6–8L in combat/heat). Dehydration causes "Desert Wither." |
| **Courtship** | Battle-defined. Forge-Tide sparring. Victor earns mating priority. Bond-Click ritual. |
| **Nursing** | Supra-pectoral pads. 5–10 day nursing window. Chorion-softening fluid. |

### 3.4 HUMANS (Kaeli)

| Trait | Detail |
|-------|--------|
| **Lifespan** | 120–150 years (magic/leyline-augmented). |
| **Build** | Standard mammalian. Highly adaptable. Crossbreeder baseline. |
| **Culture** | Diverse. Feudal kingdoms, merchant republics, cultivation clans. |
| **Naming** | Panslavonic/Interslavic/Proto-IE + Latin loanwords from Solani trade. |
| **Role** | Bridge species. Crossbreed with most races. Adapt quickly. Lower innate mana but higher stamina/chemical efficiency. |
| **Geography** | Europe + Atlantis analog. Close to Americas (Sylvani territory). Facilitates trade. |

### 3.5 FEATHERFOLK (Gryphon/Rito Inspired)

| Trait | Detail |
|-------|--------|
| **Lifespan** | 80–100 years. High metabolism. |
| **Reproduction** | Oviparous (egg-laying). 1–2 eggs per clutch. 3-month gestation in egg. Precocial hatchlings. |
| **Dimorphism** | Females larger (180–195 cm). Males smaller/more agile (165–175 cm). Reverse sexual size dimorphism (raptor model). |
| **Breasts** | None. Smooth muscular keel (avian standard). Nutrient transfer via egg yolk + regurgitation. |
| **Build** | Hollow-reinforced bones. Leathery-feather hybrid wings. Zephyr/aether dependent. |
| **Hygro-Rhizomes** | Wing joints + lower legs. Absorb atmospheric moisture during glides. |
| **Combat Role** | Aerial mobility. Glide-dodges. Wind-weaving. Storm-reading. |
| **Naming** | Wind/sky phonetics. Light consonants. |

### 3.6 BEASTKIN (Werewolf Inspired)

| Trait | Detail |
|-------|--------|
| **Lifespan** | 70–90 years. Pack-oriented. |
| **Reproduction** | Viviparous litters. 2–4 pups. 3-month gestation. Altricial (blind/deaf at birth). |
| **Dimorphism** | Males taller/bulkier (175–185 cm). Females shorter but denser (160–170 cm). |
| **Breasts** | 2 mammalian breasts (females). Lower-set. Males have vestigial glands. |
| **Build** | Dense muscle/bone. Semi-retractable claws. Enhanced chemical/thermal sensing. |
| **Hygro-Rhizomes** | Palms/soles + throat/neck sensory nodes. |
| **Combat Role** | Vanguard/bruiser. Close-quarters. Stagger-heavy. Terrain traversal. |
| **Naming** | Guttural. Pack-clan phonetics. |

| **Vampires** | Human + Sylvani DNA experiment | Varies | Viewed as cursed nobility. Blood-mages. |
| **Were-Creatures** | Human + Beastkin DNA experiment | Varies | "Strain β." Viewed as wild-born. |
| **Shamans/Druids** | Borrowed power via pact/artifact | Varies | Not transformed. Channeling. |

**Key Rule:** Vampires and Were-Creatures are both **Dark Age human experiments**. Same mechanism, different source DNA. Modern people don't know this—they assume magic/alchemy.

### 3.8 DRAGONS (Veyl'kai)

- **Nature:** Planetary mana magnets. Highest terrestrial life form. Deity-tier.
- **Language:** "The Chorus." Harmonic frequencies. Telepathic in proximity. They *sing* rather than speak.
- **Naming:** Never self-title. Known by local names given by mortals. Region-specific.
- **Alignment:** Law/Neutral/Chaotic × Good/Evil. Dictates seasons, mana tides, tribal fortune.
- **Reproduction:** Shapeshift to mate with any race. 50/50 full-blood/half-breed. Lesser-race females face the "Ordeal" (high mortality). Males often consumed post-copulation.
- **Lifespan:** 2–5× elven lifespan (2,400–7,500 years).
